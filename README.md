# hr_analysis
📌 Project Overview

This project focuses on HR Employee Attrition Analysis to identify the key factors affecting employee turnover and workforce performance.
The analysis was performed using Excel, SQL, Power BI, and Tableau to clean data, generate KPIs, create dashboards, and visualize employee trends.

🚀 Objectives
Analyze employee attrition patterns
Identify factors affecting employee retention
Create interactive dashboards for HR insights
Support data-driven HR decision making
🛠️ Tools & Technologies
Microsoft Excel – Data Cleaning & KPI Analysis
SQL – Data Querying & Backend Analysis
Power BI – Interactive Dashboard Creation
Tableau – Advanced Data Visualization
📊 Project Modules
1️⃣ Excel Module
Removed duplicates and handled missing values
Standardized department and job role names
Created calculated columns for analysis
Built Pivot Tables and KPI summaries
Developed Excel dashboards for attrition insights
2️⃣ SQL Module
Imported HR dataset into SQL database
Wrote queries using:
GROUP BY
AVG()
COUNT()
CASE Statements
Performed analysis on:
Attrition vs Department
Attrition vs Monthly Income
Work-Life Balance vs Job Role
Promotion vs Attrition
3️⃣ Power BI Module
Built interactive HR dashboards
Added slicers and KPI cards
Visualized:
Attrition Rate
Department-wise Attrition
Employee Satisfaction
Promotion Trends
4️⃣ Tableau Module
Created storytelling dashboards
Analyzed:
Business Travel Impact
Work-Life Balance
Employee Retention Trends
Department Performance
📈 Key Insights
Higher attrition was observed in certain departments
Poor work-life balance and delayed promotions increased attrition
Monthly income alone was not the major reason for employee turnover
✅ Recommendations
Improve employee engagement programs
Provide better promotion opportunities
Monitor high-risk departments regularly
Enhance work-life balance initiatives
📌 Conclusion

This project demonstrates how data analytics tools can help organizations understand employee behavior, reduce attrition, and improve workforce management through data-driven insights.
